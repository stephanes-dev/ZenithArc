# ZenithArc

ZenithArc optimizes cloud-edge workflows with concurrent multi-threading, leveraging asynchronous processing and RESTful API services.

ZenithArc is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/ZenithArc.git`
2. `cd ZenithArc`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
